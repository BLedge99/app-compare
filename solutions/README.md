# Candidate submissions

Add one implementation per immediate child directory of `solutions/`, for example:

```text
solutions/
  candidate-a/
  candidate-b/
```

Any number of candidates is supported. Give directories neutral IDs and do not include author or AI-agent names when practical. Include setup, test, and start instructions in each submission. Do not place secrets, real personal data, or unrelated projects here.

The comparison workflow treats candidate folders as untrusted and read-only. Do not put generated reports or shared benchmark fixtures in candidate directories.
